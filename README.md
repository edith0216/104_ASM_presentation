# AI Model Development Concentration
## Research Question
**Is influential AI model development concentrated in fewer organisations?**
The project is presented as an interactive Streamlit dashboard using public data from the Stanford AI Index 2025 and Epoch AI.
## Overall Finding
Influential AI model development remains concentrated among a relatively small group of organisations.
However, the level of concentration changes from year to year rather than steadily increasing.
Even when more organisations participate, a few leading organisations often still account for a large share of frontier model development.
